# WebRTC for a desktop's own backend: headset pairing by code (#212) and the
# headset's stereo video (#189). Installed by the release bundles and by CI.
# Kept out of requirements.txt on purpose: the cluster images install that
# file, and PyAV has no wheel for every cluster architecture (ppc64le); the
# EGL image adds its own aiortc build (apptainer/backend-egl-h265-overlay.def).
# Without these packages pairing answers "not-configured" and nothing else
# changes.
#
# Pinned: a release installs these with --only-binary=:all: into CPython 3.12
# on linux x86_64, macOS arm64, macOS x86_64 and Windows x86_64, so a new
# PyAV without one of those wheels must not turn up on release day. Checked
# with `pip download --only-binary=:all: --platform ... --python-version 3.12`
# for the four. av 18.1 is the last series built for CPython 3.11 (19.x needs
# 3.12), which the setup scripts and source installs still accept.

av==18.1.0
