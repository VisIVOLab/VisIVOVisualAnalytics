# Reference

One page per viewer and tool: what each menu entry, button and setting does,
in a line or two. For a task explained step by step, start from the
[use cases](../use-cases/index.md).

## Viewers

- [Spectral cube viewer](cube-viewer.md): the cube window, its panes, the
  3-D view, channels and the *Tools* menu.
- [Image viewer](image-viewer.md): 2-D FITS images, layers, contours,
  measurements and the image *Tools* menu.
- [VBT tables](vbt-viewer.md): point clouds and volumes from the VisIVO
  Server tools.
- [Velocity fields and cosmic flows](velocity-fields.md): streamlines,
  glyphs and basins of 3-D velocity fields.
- [Cubes in a VR headset](vr.md): opening a cube on a Meta Quest 3, the
  controls and the tools in the headset.

## Analysis

- [Moment maps](moment-maps.md)
- [Spectral analysis tools](spectral-tools.md): line lists, Gaussian fits,
  line-width maps, baselines, stacking.
- [Regions, PV diagrams, noise](region-pv-noise.md)
- [Kinematic Lasso](kinematic-lasso.md): select an object in 3-D with a
  double click.
- [Source finding and cross-matching](source-finding.md): SoFiA-2 and
  external catalogues.
- [Polarimetry](polarimetry.md): Stokes cubes and RM synthesis.
- [SED fitting](sed-fitting.md)
- [Cosmology tools](cosmology.md)
